明医格物 · 本草数字展馆 / 2026-11-12 新版

打开：完整保留此文件夹，双击 index.html。无需联网、安装或启动服务器。
建议使用较新版本 Chrome / Edge。手机版在浏览器中打开后同样可交互。

操作：
- 顶部章节、底部下一章或观展手册，均可直接切章。PageUp / PageDown 翻章。
- 章节正文可上下滚动；不再用滚轮强制跳章。手机可在非交互区域左右滑动翻章。
- 名医古卷：点卷翻面、点合卷返回；拖动或左右按钮切换医家。
- 本草药斗：选择八味植物，切换图像、成分指纹与传统性味资料。
- 九蒸九晒：拖动分界线比较原创示意图，调节温度与时长，切换轮次。
- 蒸馏：更换材料，调节热输入与冷却，点三个节点查看原理，支持暂停。
- 时辰：点击或拖动时辰盘，选至多三味材料，注水观察。
- 剂型：选四种剂型，沿时间查看释放示意，图表支持悬停与触摸。
- 试炼：六题均有解析，完成后可回看错题、重试、下载个人格物文牒 PNG。
- 环境音默认关闭，可在右上角开启。进度在浏览器允许时保存在本机。

数据：图表与实验指数均为教学示意，不是实测数据或实际工艺预测。
素材：新增馆藏素材来源和许可见 assets/素材来源与许可.md 与 assets/studio-sources.json。
所有运行素材已本地化；仅主动点开出处外链时需要联网。
