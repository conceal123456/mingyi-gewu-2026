明医格物 · 本草数字展览与虚拟炮制实验室
2026“守创杯”中医药科普创新创意大赛参赛作品 · 守千年本草 创智慧新生

【打开方式】
1. 将 dist_offline 文件夹完整复制到目标电脑。
2. 双击 index.html。无需安装、无需本地服务器、无需联网。
3. 建议使用较新版本的 Chrome / Edge；Firefox、Safari 与移动端浏览器亦有兼容样式。
4. 右上角“声”按钮用于开启由 Web Audio 实时合成的环境音，默认关闭。

【操作提示】
- 整页切换：点击右下角“下一章”或按 PageDown / → 换卷；也可直接点击顶部章节导航。移动端左右滑动换页。
- 首页：拖拽、滚轮、左右方向键或手机左右滑动切换五幅名医卷轴；点击卷轴展开，合卷按钮返回。
- 本草：点击百眼药斗切换药材，化学指纹谱与性味归经关系图同步更新。
- 炮制：调节温度与焖烘时长，点击“点火·推进一蒸”，观察切片、读数与动力学曲线。
- 蒸馏：切换薄荷/艾叶，调节加热功率与冷凝水流量；高功率低流量会触发暴沸预警。
- 时养：拖动十二时辰罗盘，选择日常状态，从托盘取三味食材；可注水冲泡。
- 剂型：横向拖动丸散膏丹长卷，点击任一剂型查看释放曲线。
- 试炼：答完六道情景题，生成并导出黑金通关文牒 PNG。
